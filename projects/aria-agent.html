aria-agent

Canonical clean-break agent harness: approval gates, execution tracing, and progressive-disclosure Agent Skills.

ARIA is an offline-first Python harness with bounded multi-hop execution, deterministic safety checks, retries, rate limits, ordered SSE events, dry-run replay, local memory search, and a checksummed portfolio evidence fixture. Hosted/team workflows, external notifications, OTLP protobuf/gRPC, mandatory infrastructure, and provider credentials remain deferred.
