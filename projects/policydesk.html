Support tickets in Portuguese, Spanish and English. Choose a scenario, inspect the policy clause, simulate approval, then edit the fictional order facts. Editing clears authorization and the original replay trace.

Walkthrough · actual UI, synthetic data

What the evidence shows

The CLI runs real policy, validators, SQLite audit and bound authorization around authored extraction/draft fixtures. The browser runs deterministic policy and localized templates after edits. Committed synthetic reports match the authored labels and reproduce from source-bound fixtures.

Limits

This is not an independent model benchmark, production service or consumer-law policy. No OpenAI API call, authentic provider recording, real customer, human label review or real financial action is claimed. API cost, model latency and baseline comparison remain unmeasured.

Offline CLI: uv sync --locked, then uv run policydesk demo. Dependency installation needs network access; replay does not need an API key. See the source for the complete verification commands.
