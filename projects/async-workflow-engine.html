Offline proof

The portfolio demo and automated verification run without a live database, broker, worker, or hosted model: 193 Python tests, 25 Vitest tests, and 6 Chromium smoke checks. The evidence bundle is checksum-verified.

Optional infrastructure

PostgreSQL makes runtime state durable; Redis and a Celery worker enable background dispatch; hosted LLMs require credentials. These paths are configured but no live deployment is implied.
